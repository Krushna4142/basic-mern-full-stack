## 🧩 How Node.js Works

- JavaScript runs on the server using Node
- Code is divided into modules
- Server listens for client requests
- Response is sent back to the browser

This is the **foundation of backend development**.

<h3>>🎯 Interview Preparation (Day 11 Level)</h3>

Q1. What is Node.js?

Node.js is a JavaScript runtime built on Chrome’s V8 engine that runs JS outside the browser.

Q2. Why is Node.js fast?

Because of its non-blocking, event-driven architecture.

Q3. What are modules in Node.js?

Reusable blocks of code that can be imported and exported.

Q4. Difference between Node.js and browser JavaScript?

Node runs on the server, browser JS runs on the client.
