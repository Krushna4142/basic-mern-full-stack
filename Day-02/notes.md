# 📝 Day 02 Notes — React Setup & JSX

## Why React After HTML & JS

- React builds on JavaScript fundamentals
- Manual DOM manipulation becomes hard as apps grow
- React simplifies UI updates using components

---

## What React Solves

- UI reusability
- Cleaner structure
- Predictable rendering
- Easier state management (later)

---

## JSX Understanding

- JSX looks like HTML but is JavaScript
- JSX allows embedding JS using `{ }`
- JSX must return a single parent element
- JSX makes UI code readable

---

## Files I Understood Today

- `main.jsx` → Entry point of React app
- `App.jsx` → Root component
- React renders components, not pages

---

## Key React Rules Learned

- Component names must start with capital letters
- JSX must have one parent element
- JavaScript logic stays outside JSX when possible

---

## Confusions I Had

- Why JSX works inside JavaScript
- Where React starts rendering
- Difference between HTML and JSX

---

## How It Became Clear

- JSX is converted to JavaScript internally
- ReactDOM controls rendering
- App.jsx is just a function returning JSX

---

## What I’m Confident About Now

- Creating a React app
- Writing JSX
- Modifying React components
- Running a React dev server

---

## What Comes Next
