# 🧠 Day 10 – Advanced Mini Project Notes

## Project Thinking

- Structure first, UI later
- Logic should be reusable
- State drives the UI

## Architecture

- Separate input logic
- Separate rendering logic
- Maintain single source of truth

## Key Learning

- Dynamic UI comes from state
- Clean structure = scalable project
- Real-world apps are component-driven

## Interview Point

Basic project → Feature

Advanced project → System
