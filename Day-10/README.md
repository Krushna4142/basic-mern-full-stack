## 🎯 Goal of the Day

The goal of **Day 10** is to build an **Advanced Mini React Project** with a **clean folder structure, reusable components, and scalable logic**.

This project focuses on:

- Real-world component structure
- State management across components
- Dynamic UI rendering
- Clean and maintainable architecture

- Dynamic rendering

<h3>>🎯 Interview Preparation (Day 10 Level)</h3>

Q1. Why is project structure important in React?

It improves scalability and maintainability.

Q2. What is lifting state up?

Moving state to the closest common parent.

Q3. Why use reusable components?

To avoid duplication and improve consistency.

Q4. Difference between basic and advanced project?

Advanced projects focus on architecture and scalability.
