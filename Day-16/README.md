## 🧠 What is MongoDB?

MongoDB is a:

- NoSQL database
- Document-based database
- Stores data in JSON-like format (BSON)
- Highly scalable and flexible

Instead of Tables → Rows → Columns  
MongoDB uses → Collections → Documents → Fields

## 🔄 MongoDB Flow in Backend

1️⃣ Client sends request  
2️⃣ Route handles endpoint  
3️⃣ Controller processes logic  
4️⃣ Model interacts with MongoDB  
5️⃣ Database responds  
6️⃣ Response sent back to client

Client → Route → Controller → Model → MongoDB → Response
