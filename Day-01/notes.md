# 📝 Day 01 Notes — HTML & JavaScript Basics

## Why we started with HTML & JS

- React is built on JavaScript
- Without JS basics, React feels confusing
- Understanding DOM manipulation makes frameworks easier

---

## HTML Learnings

- HTML provides structure to the page
- Semantic elements improve readability
- IDs are used to connect HTML with JavaScript
- JavaScript should be linked at the bottom of the body

---

## JavaScript Learnings

- JavaScript controls page behavior
- DOM allows JS to access HTML elements
- Events help respond to user actions
- Logic should be simple and readable

---

## Key Concepts Used

- `document.getElementById()`
- `addEventListener()`
- Conditional statements (`if / else`)
- Type conversion using `Number()`

---
