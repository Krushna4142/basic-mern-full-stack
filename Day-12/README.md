## 🧩 How Express Works

- Client sends a request
- Middleware processes the request
- Route handles the logic
- Server sends a response

This creates the **basic lifecycle of a backend API**.

<h3>>🎯 Interview Preparation (Day 12 Level)</h3>

Q1. What is Express.js?

Express.js is a minimal Node.js framework used to build backend applications and APIs.

Q2. What is middleware?

Middleware is a function that runs between request and response.

Q3. Difference between app.use() and app.get()?

app.use() is used for middleware, app.get() handles GET routes.

Q4. Why use Express instead of Node.js HTTP module?

Because Express simplifies routing, middleware, and server management.
